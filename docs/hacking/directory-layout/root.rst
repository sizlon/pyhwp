``/`` - project root directory
------------------------------

The project root directory contains project configuration files.

:file:`pyproject.toml`
   ``pyhwp`` project file.

:file:`setup.py`, :file:`setup.cfg`
   ``pyhwp`` setup files.

:file:`Makefile`
   Makefile for project management.

:file:`buildout.cfg`
   `buildout <http://www.buildout.org>`_ configuration file.

:file:`tox.ini`
   `tox <http://tox.testrun.org>`_ configuration file.

:file:`requirements.in`
   Dependencies specification file.

:file:`requirements.txt`
   Compiled dependencies specification file. Auto-generated by ``make update-requirements``.
